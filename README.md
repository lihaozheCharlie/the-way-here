# The Way Here

[English](README.en.md) | 中文

先说说最近的事，它帮你整理成一份存在你电脑上、能回看也能追问的人生知识库。

> 十多年来，我记了600多篇日记，拍了上万张照片。可真正想回头看看时，脑海里往往只剩几个模糊的瞬间。

![此刻页：随手记一段近况](docs/images/now.png)

[安装与启动](#安装)

## 它能做什么

**随手记下最近的事。** 在「此刻」里打字，或者直接说出来（语音在本机识别，仅桌面版）。可以「只存原文、稍后再整理」，也可以点「整理成日记」，让它帮你整理好。

**没写日记的日子，从照片开始。** 在「此刻」里点「找照片」，从 Mac 照片库挑出一组，圈出里面的人，它会起草这组照片背后的故事，你改好再保存（仅 macOS 桌面版）。

![一组照片圈出人物后写成的故事](docs/images/photo-memory.png)

**回头读懂自己。** 「已有理解」把记录整理成对自己的理解、人生轨迹和人与世界。想听它怎么看你的近况，就请它写一封回信；哪里没读懂，在右侧接着问。

![读一封近况回信](docs/images/letter.png)

## 记录在哪里

数据存在你自己的电脑上，服务只监听 `127.0.0.1`。

只存原文、稍后再整理时，打字和语音都不出本机。点「整理成日记」、对话或写回信时，相关文字会发给你配置的模型，比如通过本机的 `codex` CLI，或者你自己配的 provider。

照片也一样：找照片时只在本机读取和浏览，人脸识别和头像裁剪也在本机完成。只有让它写照片故事时，才会把所选照片的预览图，连同你填的人名和文字，一起发给你配置的视觉模型。

## 安装

```bash
git clone https://github.com/lihaozheCharlie/the-way-here.git
cd the-way-here
bash start.sh
```

需要 Python 3.9+。脚本会自动准备 Node.js 22.19+ 和 pnpm，安装依赖并构建。完成后打开 http://127.0.0.1:4321，按 Ctrl+C 停止。第一次打开的是自带的匿名演示库，自己的空间在页面左上角创建。

**配置模型**（整理成日记、写回信、对话都需要）：本机装好并登录 Codex CLI；或者在「偏好设置」的「AI 助手」里选一个模型厂商，填入 API Key，Key 只保存在本机。写照片故事需要一个能读图的模型。

**桌面版**（仅 macOS，包含语音输入和照片记忆）：

```bash
cd studio && pnpm install && pnpm desktop
```
