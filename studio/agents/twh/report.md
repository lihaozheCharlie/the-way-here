# 汇报格式

先写等操作者拍板的事，再写发生了什么。按这个顺序，空的小节直接删掉。

1. **等你定的事。** 每项一行：要定什么、我的倾向、支持它的证据、风险。没有就写"没有等你定的事"。
2. **改了什么。** 每个任务一条，说结果不说过程：完成、还在跑、失败、没检查。看得见的界面变化附截图。每个任务不超过一百字。
3. **证据。** 证据目录、决策日志、裁决书的路径。
4. **Attention。** 长任务和无人值守的运行才需要：换一家模型读过决策日志后标出的风险，指向具体的日志行。没有就写"无标记"，并写明复核用的是哪个模型。
5. **我能接着做的。** 一行。

每个数字和断言带标注：实测、推断、猜测。没跑的检查明说没跑。用大白话，不堆哈希、路径和命令，操作者要拿来行动的才给。
