# Mac App Store 系统核查（2026-10-22）

范围：已提交的 0.1.2 build 11、修复中间包 build 12/13、最终核查版 build 14，以及当日 App Store Connect 资料和公开隐私/支持页。分发修复基于原始已上传安装包，只加入本文列出的修复，未混入工作区其他尚在开发的产品改动。结论只覆盖本文明确列出的证据，不代表 Apple 保证通过。

## 查出的实际问题与处理

| 问题 | 证据及影响 | 处理 |
| --- | --- | --- |
| Python 包含安装协议支持 | 原包 `urllib/parse.py` 及缓存字节码含 `itms-services`，对应本次 2.5.2 拒绝 | 按 CPython 官方合规补丁移除该项和缓存，增加所有普通文件扫描 |
| 校验工具可间接执行工作区 Python | 固定校验入口仍会启动工作区子脚本。隔离复现实验中，旧运行器执行了测试用可变脚本，新运行器未执行它 | 子脚本映射回签名引擎，递归通过同一运行器；隔离 Python 启动；拒绝 shell、`-c`、可执行程序覆盖及直接进程执行；用 `--` 分隔工具参数，防止覆盖运行器绑定的工作区 |
| 不必要的包安装器 | 运行时仍包含 pip/ensurepip，而产品只使用已随包的工具和 PyYAML | MAS 资源移除包安装器和其入口，PyYAML 保留 |
| 默认用途说明与功能不符 | Electron 主应用包含相机、蓝牙、系统音频捕获的泛化说明；照片文件导入不等于使用相机 | 清理这些用途说明；麦克风和语音识别说明保留；不影响另行实现的照片库用途说明 |
| 宽泛网络例外 | 默认 Info.plist 开放任意 ATS 加载 | 移除例外，保留标准安全默认行为；实际外部 AI 使用 HTTPS |
| Markdown 可触发任意外站资源请求 | 笔记/模型回答可包含远程图片；缺少页面资源来源限制 | 桌面页面增加 CSP，仅允许同源与明确的本地 data/blob 资源；外链仍须用户操作，安装协议被白名单拒绝 |
| 开发测试代码进入发行资源 | 原 app.asar 含 8 个桌面测试脚本；未来测试用安装协议可能再次进入发行包 | 从正式打包及修复包排除桌面测试脚本 |
| Python 动态库包含本机安装标识 | 动态库 ID 带构建机绝对路径；它不是实际运行时外部依赖，但不应随包保留 | 改为随包 `@rpath` 标识并重新签名 |
| 模型来源链接可能打开空白页 | 实机查询回答正确，但 `app/demo/sources/...md` 被当作相对 URL；点击后路径错误 | 本地引用解析支持托管空间和来源相对路径，并拒绝伪装成文件的外站链接及遍历路径；增加渲染及路径测试 |

凭据扫描另命中一项官方 Codex 静态数据格式标记，已与固定官方 0.162.1 vendor 二进制逐字节匹配，属于误报。检查器只豁免该组件中的精确指纹，并在结果中报告；不豁免其他文件或其他疑似凭据，不输出匹配正文。

## 已核对的其他边界

- 桌面运行时使用私有 IPC，没有 HTTP/TCP 监听入口或 `network.server` 权限。渲染器启用 sandbox/contextIsolation，禁用 Node 集成；外链仅允许 HTTP、HTTPS、mailto。
- 固定 Codex 不导入插件、MCP、用户配置或历史；MAS 参数禁用 shell、插件、依赖安装和相关扩展能力。模型工具由应用校验路径、任务绑定和写入权限。Codex 保留，没有以移除功能规避审核。
- Python 只从签名引擎加载工具，用户知识资料作为数据；普通更新仅经 Mac App Store。未找到应用自动更新器或未经许可注册登录启动的调用。
- 原始第三方模型 Key 不打包；桌面 AI 设置使用系统支持的加密，不回退明文。ChatGPT 登录材料按用户选择导入应用私有目录，并以受限文件权限保存；这部分与 API Key 的加密机制不同，政策已分别描述。
- AI 任务须匹配当前接收方的明确许可；撤销及切换接收方的逻辑和测试已核对。本地浏览/搜索可独立使用。
- 公开隐私政策与支持页无需登录。政策列明 AI 厂商、内容范围、境外处理可能性、费用、语音服务、撤销和本机清理方式。App Store 已发布六类隐私数据，均按当前后台标为与身份关联；没有声明广告追踪。隐私分类与当前资料处理方式未发现明显冲突。
- App Store 类别为“生活”，与包内类别一致；当前年龄分级为 9+，保留既有问卷结果。免费、商店截图和功能介绍需持续与实际版本一致，不把模型额度包含在免费下载中。
- 最终包继续检查私有系统库、PrivateFrameworks、本机外部依赖、符号链接、签名和安装协议；扫描不是对所有未知私有 API 的数学证明。
