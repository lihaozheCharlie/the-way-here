本政策说明 The Way Here macOS 应用如何处理你保存的记录、导入的资料，以及使用语音和 AI 功能时涉及的信息。

你保存在本机的资料

应用在本机保存知识库配置、生活记录、导入资料、生成的知识页面以及相关对话、索引和任务记录。连接外部笔记文件夹时，原始笔记保留在原目录，应用按你授予的访问权限读取资料；AI 是否可以修改目录内容，以你在应用中的授权和具体任务为准。

目前的应用架构不要求创建 The Way Here 云端账号，也不提供运营者托管的知识库云同步。你自行使用的系统备份、同步盘或其他应用可能处理这些本地文件，受对应服务的设置和政策影响。

可选 AI 功能

AI 功能通过你选择并配置的服务提供。任务可能发送你的输入、相关日记或对话片段、知识页面、照片预览、账单内容及其他任务上下文，并将服务返回的结果保存到本机。AI 可能继续读取任务相关资料，并非总是只发送当前输入框的一句话。

使用外部 AI 服务会让相关信息离开设备。服务提供方的处理地点、数据保留、模型训练使用和删除方式取决于其条款及你的账户设置。我们不能代替服务提供方承诺不保留或不用于训练。应用免费不代表第三方模型服务免费。

仅你选定的服务接收该任务，不会同时发给全部服务。服务及请求地址与官方政策如下：

  • DeepSeek（api.deepseek.com）：官方隐私说明
  • 智谱 GLM（open.bigmodel.cn）：官方隐私说明
  • 阿里云百炼中国站（dashscope.aliyuncs.com）：官方隐私说明
  • Kimi（api.moonshot.cn）：官方隐私说明
  • MiniMax（api.minimaxi.com）：官方隐私说明
  • OpenAI API 与外部 Codex（api.openai.com / chatgpt.com）：官方隐私说明
  • Anthropic（api.anthropic.com）：官方隐私说明

内置第三方模型连接通过 HTTPS 直接发往选定厂商，不经过运营者的 AI 中转服务器。外部 Codex 的连接与扩展还取决于用户自己的配置。接收方处理请求内容、身份验证凭据、IP 等连接信息。其保留、训练使用、删除和处理地区依账户、合同及官方政策而定，本应用不承诺零保留。选择 OpenAI、Anthropic 等境外服务可能将任务内容传往美国及其他国家；请先确认资料和账户适合使用该服务。应用内置模型连接不会自动切换接收方；外部 Codex 中由用户配置的扩展或服务需单独核对。

应用会在首次向所选 AI 服务发送资料前告知接收方、资料范围和用途，并请求你的明确同意。你可以拒绝或撤销，继续使用不依赖外部 AI 的本地资料浏览和搜索功能。更换接收方或扩大资料范围时需要重新确认。撤销不代表第三方已经收到的资料自动被删除。

语音与照片

语音输入在你主动开始录音并允许麦克风及系统语音识别权限后使用。语音识别在本机完成，原始录音不会上传；轻量版本需要 macOS 中文听写资源，由系统管理。识别结果可编辑，确认后用于记录；如果另行使用 AI 整理，转写内容及相关上下文会按 AI 功能说明处理。系统资源未就绪时会提示启用中文听写，不会自动切换到云端识别。

照片由你选择导入，应用会在本机保存及处理相关图片。启用需要图像输入的 AI 功能时，所需图片或预览可能发送给对应服务商。导入照片本身与向 AI 发送照片是不同操作。

密钥和应用设置

你配置的模型 API 密钥用于向所选服务进行身份验证。打包桌面版使用 macOS 系统钥匙串支持的加密保存 AI 设置与 API 密钥，系统加密不可用时不会回退明文。官网版可连接你已安装的 Codex CLI，使用你选定的登录与配置目录。Codex 的账号、凭据、模型、插件和其他外部服务取决于你自己的安装与配置；这些设置可能改变资料接收方或可访问范围，请在连接前核对。应用不会将该配置目录整体复制到自己的数据目录；外部 Codex 可能使用或刷新其中的登录材料。请保护本机账户和备份，不要分享含密钥的配置或日志。可在“偏好设置 → AI 助手 → 第三方模型”选择对应厂商并点击“移除”清除该厂商的 API Key；还应在厂商后台撤销不再使用的 Key。

保留 删除与撤销

你可以在应用中删除相应记录、断开外部目录或删除知识库。断开目录不会删除原始文件。删除一条记录并不保证对话、任务快照、备份或已经发给服务商的副本同时被删除。卸载应用也不等于自动清除所有本机资料。

如需完整重置，先备份需要保留的资料并完全退出应用。通过 Finder“前往文件夹”检查 ~/Library/Application Support/The Way Here/ 中的本应用数据（官网版），确认后移至废纸篓。此操作会移除应用管理的知识库、索引、对话、任务快照、设置；外部 Codex 的登录材料仍位于你自己的配置目录；外部工作区、原文件及备份需分别处理。不要删除其他应用的数据目录，清空废纸篓前再次确认备份。移除本机凭据不会注销服务商账号或撤销服务商端 Key。你可以通过系统隐私设置撤回麦克风等权限。对于第三方服务已经处理的数据，请使用该服务商的隐私设置或权利申请渠道；如需协助，联系本政策邮箱。

分析与其他共享

应用未接入运营者的广告跟踪或主动使用分析上传服务。可选 AI 与系统语音服务仍有上文所述数据处理。你主动发送问题反馈或诊断材料时，我们会使用你提供的邮箱及材料处理问题；请先移除不必要的私人记录和密钥。

反馈材料仅在处理问题、后续联系及必要法律留存所需期间保留，到期删除或匿名化。可通过客服邮箱提出删除请求。如未来增加其他数据处理目的或接收方，我们会更新说明，并在需要时重新征求同意。

你的选择与联系

请仅导入你有权使用的资料，尽量避免将他人的敏感信息发送给外部 AI。你可以通过 644730894@qq.com提出访问、更正、删除、撤销或其他隐私请求。运营者无法远程访问你的本机知识库；涉及本机资料的操作需要你在自己的设备上完成。
