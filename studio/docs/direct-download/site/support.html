The Way Here

使用帮助与支持

The Way Here 帮助你在 Mac 上记录生活、整理资料，并回看一路走来的变化。

第一次打开

你可以先浏览应用附带的匿名演示空间，再使用“开始我的空间”创建自己的知识库。演示内容用于体验产品，不是对你个人的分析结果。

保存记录与打开文件夹

使用侧栏或菜单栏中的“随手记”留下新记录。通过“生活记录”或资料导入入口选择支持的资料；连接已有笔记时，通过系统文件夹选择器授权访问。断开连接会停止同步，不会删除原目录文件。

AI 是否免费

App 首版免费下载，本地浏览和搜索已有资料无需配置 AI；随手记的 AI 整理保存需要配置模型服务。使用 AI 需要在偏好设置中选择所支持的服务并完成配置；服务商可能另行收费，下载应用不包含模型额度。请查看发送前说明，决定是否允许发送相关资料。

连接 Codex

官网版连接你已安装并登录的 Codex CLI。使用“偏好设置 → AI 助手 → 连接已登录的 Codex…”依次选择 Codex 程序和登录配置目录；外部 Codex 的配置、插件与会话由你自己的 Codex 安装管理。也可选择第三方模型并添加自己的 API Key。无论哪种方式，都需要另外同意资料发送才可运行 AI。

语音与权限

语音输入需由你主动开始，并允许麦克风与系统语音识别权限。如果拒绝，可继续键盘输入。语音在本机识别；请先在 macOS 系统设置中启用中文听写，并完成系统语音资源下载。应用不再附带独立语音模型。识别结果应在保存前核对。

更新和备份

官网版请回到下载页面获取新版，完全退出应用后替换“应用程序”中的旧版。官网版暂未提供自动更新。重要资料请自行备份，删除知识库或清理数据前先核对备份是否完整。系统和第三方同步盘的备份规则由相应服务决定。

检查更新

0.1.4 起，官网版启动后自动检查新版。有更新时可查看说明并点击“下载更新”，也可稍后再处理。在“偏好设置 → 通用 → 应用更新”或应用菜单中可手动检查。网络失败不影响本地使用；下载后完全退出应用并替换安装。旧版须先手动升级到 0.1.4。
