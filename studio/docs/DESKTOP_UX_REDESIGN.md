## 自动验证

基础质量门：在 `studio/` 运行 `pnpm typecheck`、`pnpm test`、`pnpm build`。

桌面集成：`pnpm desktop:verify` 在临时匿名空间中运行真实 Electron 客户端，覆盖：

- 12 个栏目在常规窗口中可进入，主要内容无横向溢出；1100×780较小窗口复核。
- 原生菜单、命令搜索、Inspector展开/收起；非法IPC外部导航被拒绝。
- 文件夹240/48px、文件列表280px；属性与目录展开/收起。
- 阅读/编辑字体一致；800ms自动保存落到真实文件，frontmatter与原始标题保留，成功状态消退。
- AI历史切换保留当前草稿；四类理解、循环四阶段、模型校准与关键词高亮。
- 整理提示/每日话头跨窗口同步；空间重命名实际保存。
- 随手记置顶及全局快捷键已注册；重载后草稿和标题恢复；语音转写进入正文；明确保存；跨库保存被拒绝。
- 独立阅读只读、独立深聊可打开；照片导入入口。
- 原目录连接、外部编辑刷新、双链/反链/标题定位、来源只读、连接重启持久化、断开不删除原始文件。

测试中禁用真实AI模型调用，语音识别返回由测试替身提供；运行时、工具调用、审批、失败和写入协议由服务端现有集成测试覆盖。麦克风授权、真实语音识别质量与第三方模型连通性取决于用户本机授权和模型配置，不伪造成功结果。

## 独立复核

初次独立复核提出七项修正，均已关闭：

1. 来源页在1380和1100宽窗口保留并排、可读的完整正文；来源Inspector与文件夹按可用空间让位，仍可手动展开。两栏同时折叠也保持各48px。
2. Questions及聚焦子页输入框、发送按钮和状态行保持可见；上下文和证据各自滚动。
3. 移除内嵌对话无效关闭按钮；完成后关闭回到初始话题。
4. 设置页签单行显示、滑动高亮与选中内容一致。
5. 随手记输入框统一描边、8px圆角及焦点环；防抖300ms、关闭兜底、成功提示1.6秒后淡出均已落地。
6. 移除设置说明的装饰性厚边线与理解卡片重复眉题。
7. PRODUCT.md、DESIGN.md和本地设计sidecar与新桌面交互、配色和控件保持一致。

独立复核最终处置为 `ship`，范围为设计稿对应截图、上述七项修正及聚焦子页补充复核。

## 2026-09-13 代码与设计复审

本轮重新核对设计稿、全部未提交改动、共享控件、数据来源与桌面回归。上轮通过的检查并不意味着细节没有遗漏，本轮发现并修复以下问题：

| 级别 | 问题 | 修正与验证 |
| --- | --- | --- |
| P1 | 理解摘要的标题来自最新页面，模型正文却来自另一个总览；循环也可能回退到其他循环 | 优先具体页面，模型按相同页面 ID 读取，循环仅匹配同一 ID；增加两项来源一致性回归，加载失败显式提示 |
| P1 | 演示提示条异步出现后，对话区位置变化却不重新计算高度，输入框可能越出窗口 | 高度观察覆盖外层页面容器；增加120px提示条延迟插入与移除的回归，检查输入区保持在窗口内 |
| P2 | 来源全文阅读缺少目录；知识页目录使用未去标题的 Markdown，可能导致标题序号错位 | 阅读与目录使用一致正文；来源也提供44/240px目录入口；独立只读窗口避免重复目录；桌面回归实际点击标题验证跳转 |
| P2 | 保存提示清空文字后才开始淡出，实际看不到淡出，停留时间也不符 | 200ms淡入、1200ms停留、200ms保留文字淡出，再清空；保存错误持续显示；模拟409检查提示保持且文件不被修改 |
| P2 | 标题栏仍使用纸白底及硬分隔线，与设计稿统一画布底色不符 | 改为canvas并取消分隔线，同步DESIGN.md |
| P2 | 四阶段使用真实长内容时卡片过高 | 阶段摘要限制三行，完整内容仍由页面标题链接访问 |
| P2 | 原桌面检查在循环或模型按钮不存在时跳过，可能掩盖漏实现 | 匿名数据固定存在时改为必须显示；增加来源目录、保存失败检查；截图等待折叠/页签过渡结束 |

可维护性方面，将模型内容读取拆成独立组件、把卡片配置移到渲染函数外，并展开分段页签的键盘处理与测量逻辑。没有为审查重新改写不相关的领域模块。

设计稿各章节的对应关系仍见上表；来源页窄窗口折叠辅助栏属于保留阅读宽度的适配，真实知识内容替代稿中示例。回信横幅按存在近期回信显示，不声称实现了未读计数。

最终验证使用重新构建的macOS应用包；真实AI模型调用和麦克风识别质量仍不属于模拟回归可证明的范围。
