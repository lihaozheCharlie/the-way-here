# 此刻：随手记与找照片

随手记内的来源切换复用蓝白色分段控件。macOS 主窗口提供“说或写 / 找照片”；浏览器、其他平台和独立随手记窗口保留原文字语音入口。未来的日历来源没有开放。

| 环节 | 行为 |
| --- | --- |
| 来源切换 | 保留文字、筛选、结果和已选照片；支持方向键、Home/End。录音期间禁止切换。 |
| 授权 | 首次授权、拒绝或系统限制在照片面板内呈现；支持系统设置及重新检查。 |
| 常用筛选 | 时间快捷项、地点及附近范围。时间描述与明确起止日期互斥。 |
| 更多筛选 | 时间依据、日期、相册与刷新、照片类型、收藏；折叠后显示可单独移除的条件。 |
| 搜索 | 支持回车、取消、空结果、清除条件、分页；结果内部最高 372px 滚动。 |
| 照片选择 | 缩略图选择，独立放大按钮和弹窗选择；最多 50 张。iCloud 需先明确下载预览。 |
| 带去整理 | 本地准备 JPG 后进入确认位置；展示缩略图、标题、目录、文件数和真实大小。返回保留选择。照片页脚目录选择贯通确认页和实际导入，与文字草稿目录独立。 |
| 写入 | 点击“开始认人物”才导入；图库原文件不变。 |
| 认人 | 复用现有圈选、拖动缩放、人物关联和同组同步；可跳过。 |
| 讲故事 | 全组照片一篇故事；明确点击“AI 帮你写”才发送预览，用户核对后收进理解。 |
| 恢复与完成 | 中途关闭从历史继续；成功构建后关闭弹窗、清空选择并提供记录链接，包括从历史恢复的流程。 |

系统图库导出为去除 EXIF/GPS 的本地 JPG 副本，最长边 7000px，单次响应最多 8MB；导入仍受单批 100MB 限制。导出过大、权限撤回或资源失效时保留选择并提示重试。照片搜索、导入和后续任务始终绑定启动时的知识库 ID。

## 验证

在 Studio 目录运行 `pnpm typecheck`、`pnpm test`、`pnpm build`。构建后运行 `node scripts/verify-capture-sources.mjs` 可执行专门的匿名浏览器验收。脚本使用临时 demo 副本和明确标识的合成风景图，模拟 macOS 图库及模型返回，不访问私人照片、不调用真实模型；结束时关闭浏览器、服务和端口并删除临时资料。

该验收覆盖授权与拒绝、录音时切换锁定、来源键盘操作、筛选和草稿保留、iCloud 显式预览、50 张上限、导入前确认、真实本地导入、故事恢复、模拟 AI 起草/完成、空结果、取消、1024px 桌面及非 macOS 隐藏入口。原生照片库实际授权与真实模型生成需在桌面应用中验证。


## 设计稿复核补充

逐状态复核修正了这些此前验收未覆盖的情况：照片故事线索输入直接可见，照片条默认展示前 14 张并可展开全部；已发起的“收进理解”任务 ID 持久化，关闭窗口后完成或失败均可恢复处理；完成旧记忆仅取消该批照片的选择，不清除后来另选的照片；50 张、每张 40 个人物的草稿也可完整恢复。照片选择条使用不会形成额外滚动容器的裁剪，保证底部吸附生效。图库下载授权沿用到同张照片的大图预览；人物候选显式绑定照片记忆所属知识库。


新增中断验收使用合成检测框和特征向量，验证检测中关闭后仍能将同一人物同步到两张照片，并通过键盘调整人物框后核对服务端保存的实际坐标。对恢复中的慢任务，状态确认前锁定写入动作并提供失败重试；完成后同步清除恢复检查点，再次打开已完成记忆不会自动关闭。上述过程仍不读取真人照片或调用真实模型。
