# 生活记录新版 UX 验收

本次依据：用户提供的 `source-tree-and-document-outline (2).html`（2026-10-10）。实现范围为生活记录页面及它使用的目录树、文件列表、导入入口、阅读/编辑和小标题导航。设计稿外面的演示开关、固定示例数据和模拟 toast 不进入产品；窗口搜索、Agent、空间切换和其他页面导航继续使用已有真实功能。

## 逐项覆盖

| 设计内容与交互 | 实现与核对 |
| --- | --- |
| 应用外壳风格统一、紧凑工具栏 | 遵从用户最新截图反馈，标题栏、主侧栏和蓝色选中导航沿用全应用样式；浏览器反复切换值得聊聊与生活记录并比较背景、宽度、间距和导航尺寸 |
| 全部、笔记、AI 对话、照片、账单、待构建及真实计数 | 浏览器逐个点击、核对真实文件类型与列表；待构建保留直接构建的复选框与批量操作 |
| 标题或内容搜索 | 通过索引全文搜索，而非仅标题和摘要；浏览器核对正文独有关键词、无结果与清空恢复；HTTP 测试核对 35 份来源全部返回，普通命令搜索仍限制 30 条，Wiki 页面不混入来源结果 |
| 导入资料直接打开 | 点击立即打开导入窗口，不出现中间菜单；三类材料逐个切换，核对与下方文件夹提示均为 16px 间距，提示无灰色说明文字；Esc 关闭窗口 |
| 导入的具体流程 | 保留三类材料选择、格式提示、解析、保存位置树、创建嵌套目录；日记笔记转到打开文件夹。既有导航验收实际上传匿名聊天文件并检查目标目录；照片、账单流程由原有回归测试覆盖 |
| 三栏布局 | 文件夹 216px、文件列表 252px、剩余文档；统一 12px 外框、44px 栏头；文件夹与文件列表独立滚动，文档独立滚动 |
| 两个分栏收起/展开 | 收起只保留 40px 竖排入口；逐个点击并测量宽度、检查恢复；隐藏内容保持挂载 |
| 文件夹首次使用 | 无目录时隐藏顶部重复打开按钮和“全部材料”，居中显示文件夹图标、说明及打开按钮；新建文件夹/记录、排序禁用；文件列表与预览各有空态 |
| 打开磁盘文件夹 | 原生目录选择器接入现有目录连接 API；成功后刷新并选中新根；匿名浏览器通过桌面桥接替身验证请求及新根出现 |
| 原样多级目录 | 按实际目录懒加载，保留空目录、不可用根和重新连接；跨库恢复状态有代次保护；服务端目录与安全测试覆盖越界、符号链接等 |
| 全部材料 / 目录选择 | 全部材料始终包含所有后代；选中目录默认仅显示该层文件；“含子文件夹”保留在更多菜单中；切换目录清除月份并重置文件选择 |
| 文件夹的“＋” | 在当前选中目录内原位新建；全部材料位置禁用。Enter 提交、Esc 取消，保留中文组合输入检查和出错反馈 |
| 文件夹更多操作 | 新建子文件夹、子目录重命名、Finder 显示、废纸篓；顶层外部连接使用从列表移除且原文保留。浏览器逐个点击，验证请求、取消与确认；根重读和不可用根重连保留 |
| 文件夹键盘操作 | 共享树 roving tabindex、方向键、Home/End、Enter/空格、⌘⇧N、Shift+F10；既有验收覆盖方向导航和快捷新建，完整键位逻辑经代码核对 |
| 文件名和一行摘要 | 紧凑 13.5px 文件名、12px 摘要、浅蓝选中，悬停/键盘焦点显现更多按钮；超长内容省略并保留可读正文 |
| 新建记录 | 当前目录的“＋”打开行内标题输入，Enter 创建并刷新列表、选中记录、进入编辑；Esc 可取消，忙碌和错误状态保留 |
| 筛选与排序 | 最新/最早、全部月份和各月真实计数、批量选择；逐个点击排序、月份并核对列表与月份重置 |
| 批量选择 | 进入待构建，直接构建项可单独选择和全选；浏览器检查单项取消/恢复及批量 Agent 请求的两个绑定文件 |
| 文件更多菜单 | 构建文档、行内重命名、打开原始目录、删除；照片/账单使用其真实记忆入口。浏览器检查单篇构建的文件路径、重命名 409 错误后重试、打开目录请求、删除取消及确认 |
| 顶部路径与状态 | 显示完整路径的 title 和路径分段、文件名、修改时间；编辑中、正在保存、已保存及错误状态在右侧；滚动时保持栏头可见 |
| 正文无阅读/编辑按钮 | 默认阅读，双击正文进入 Markdown 编辑，Esc 完成；保留 F2/Enter、自动保存和 ⌘S；不会改变其他文档宿主的显式模式切换 |
| 文档小标题默认展开 | 同一个目录组件，以 150px 文本列展示，子层缩进、当前章节强调；至少一个二级或更深标题就显示，文章标题不会充当小标题 |
| 小标题收起 | 28px 刻度轨、主要/子级短线、活动刻度；悬停或键盘聚焦浮出同一目录，展开按钮可实际点击，偏好单独存储 |
| 没有小标题 | 不留导航占位；编辑时显示“输入 ## 添加小标题”，输入标题后实时出现目录并隐藏提示 |
| 目录定位与编辑 | 阅读随滚动，点击定位留出顶部栏和 24px 阅读空间；编辑跟随光标，点击目录后光标到标题行末并保持焦点；正文输入和自动保存实测通过 |
| 去掉额外关联面板，保留照片与账单能力 | 来源预览不显示右侧目录/关联标签；正文下方恢复可收起的关联卡片，包含相关日记和知识页面，检查链接、展开全部与收起。知识阅读页原有关系导航继续回归验证。照片与账单记忆和现有批量构建机制保留，历史版本/独立窗口仍只读 |
| 统一移除只读提示 | 文档正文、历史版本、目录导航、文件预览弹窗不显示只读提示，编辑能力保持原样；浏览器检查历史版本无编辑按钮及无只读徽标 |
| 关联模块的阅读/编辑切换 | 阅读态正文至卡片间距不超过 64px，短正文不撑出最小高度；编辑态保留原始相关日记及关联段落，隐藏下方重复卡片，退出编辑后恢复 |
| 宽屏和收起分栏后的留白 | 阅读区域居中，正文与导航固定相隔 16px；预览宽度达到 1000px 时正文可用宽度为 680px。1440/1920px、两栏展开/收起核对实际坐标及栏头满宽，截图人工复核 |

最终验证通过：类型检查、527 项测试、生产构建、两份浏览器验收脚本及差异空白检查。

## 验证边界

浏览器验证中的原生目录选择器使用桌面桥接替身；Finder 显示、文件夹废纸篓和重连使用 API 替身核对交互与请求，真实磁盘边界由既有服务端测试覆盖。本次未在真实 macOS Finder/系统授权窗口中手工完成选择、重连、自动化授权、废纸篓恢复等操作，也未把模态交互测试称为真实 OS 验收。

大目录性能、屏幕阅读器完整朗读、中文 IME 长篇编辑及外接盘权限状态不是本次自动化的覆盖结论。
