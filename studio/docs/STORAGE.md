# 应用存储与缓存

生活记录 Markdown 是用户的知识资产，只保存整理正文。输入原话、录音和恢复材料保存在应用层，不随知识目录进入 Wiki 索引。本次提供目录隔离、分类协议和只读查询，为后续缓存清理功能准备；不自动删除历史内容。

## 目录

- 桌面缓存根：Electron `userData/cache/`，通过 `TWH_APP_CACHE_ROOT` 传给本机运行时。
- 录音：`cache/speech-recordings/<session>/`。
- 随手记原话：`cache/vaults/<workspace-hash>/capture-inputs/<knowledge-base-hash>/<run-hash>.json`，包含当前与历次输入。
- 日记覆盖前的版本：`cache/vaults/<workspace-hash>/capture-versions/<knowledge-base-hash>/`。
- 非桌面缓存根：原有工作区应用状态目录下的 `cache/`。macOS 状态目录为应用支持目录 `the-way-here/vaults/<workspace-hash>/`；Windows 和 Linux 沿用已有状态路径。
- 必要状态仍在原有状态目录；不改变设置、会话、任务和草稿的位置。桌面 `userData` 中的工作区选择、授权书签、登录、偏好和浏览器草稿也必须保留。

输入缓存先于 Markdown 写入，使用原子替换，文件权限 0600。应用重启可通过任务 ID 找回原话。缓存缺失时，已保存日记与历史索引仍然可用，继续编辑改用整理稿作为起点；未提交补充独立保存在必要状态中。

## 清理分类

唯一机器可读分类在 `apps/server/src/services/storage-policy.ts`，只读接口为 `GET /api/storage/policy`。`rebuildable` 表示满足前提后可重建，`conditional` 表示有损清理必须检查保存状态和用户意愿，`protected` 表示不能由缓存清理删除。

| 数据 | 分类 | 清理前提与影响 |
| --- | --- | --- |
| `recognition-input.wav` | 可重建 | 同一会话录音及识别均已结束，完整 `recording.caf` 仍可读取；只删除转换文件 |
| 随手记输入原话和历史输入 | 条件清理 | 对应任务已结束、日记保存完整、无未提交编辑依赖；失去原话查看及从原话重新整理能力 |
| 日记旧版 Markdown 备份 | 条件清理 | 新版日记保存成功且不在恢复中；用户接受失去旧版恢复能力 |
| `recording.caf`、预览和最终转写、时间轴 | 条件清理 | 可能是唯一副本；录音到日记尚无持久关联，现阶段必须人工确认，不可按年龄直接删除 |
| 未保存草稿、已保存记录的未提交补充 | 必要状态 | 不清理；成功保存前始终保护 |
| 历史元数据、默认目录、版本哈希和删除标记 | 必要状态 | 不清理；删除标记防止已删除历史被旧任务重新导入 |
| 活动任务、恢复状态、审批、差异及会话 | 必要状态 | 不清理；终态任务须另做保留和脱敏策略 |
| AI 配置、登录、文件授权、空间位置、偏好 | 必要状态 | 不清理；不可删除整个 userData 或状态根 |
| Wiki、生活记录、原始来源、导入登记、照片原件与人物裁剪 | 用户资产 | 不清理；隐藏目录、图片预览也可能是唯一副本或已被引用 |
| 随应用分发的 Whisper/VAD 模型、执行程序、公共知识引擎 | 运行依赖 | 不属于用户缓存，不清理 |
| 未登记的新目录 | 默认保护 | 先明确生产者、消费者、唯一副本和重建方式，再加入分类 |

不能递归清空 `cache/`：其中可能有进行中的录音或尚未安全保存的唯一输入。未来清理必须在执行时重新检查活动任务、录音/识别所有权、草稿引用和目标文件，检查和删除期间防止并发使用；目录扫描不能跟随符号链接。只有格式和引用都明确的文件可进入删除计划。

## 运行副本和迁移

运行记录中的 prompt/outputTarget 仍包含原始输入，供任务恢复和审计使用。删除输入缓存不等于删除这些运行副本，也不表示清除了个人数据；未来需单独处理终态任务的保留、脱敏、恢复和历史重建，不能删除活动任务或把运行根当普通缓存。

旧版 `userData/speech-recordings/` 和状态目录 `capture-versions/` 保持原位置，列入条件清理分类；不自动移动或删除。旧历史 JSON 在正常写入时把原话字段移入缓存；旧 Markdown 内的“输入原话”兼容读取，本次不批量改写。知识原件和运行依赖完全不参与此次搬迁。
