2

生活记录:文件夹栏 = 磁盘上的真实目录

不再按“日记 / AI / 账单”归类,也不再只有一级。每个打开的文件夹作为一个根,下面按磁盘原样逐级展开;名称、层级、顺序与 Finder 一致。下方原型可直接操作:点箭头展开、点行选中、↑↓←→ 导航、悬停行点 “…” 打开菜单。

  • 现状:只有一级,深层目录被压平
  • 现状:图标按内容类型区分,和磁盘不一致
  • 现状:“打开文件夹”藏在导入弹窗里

一棵树,两组根

“已打开的文件夹”是用户授权的外部目录,每个根用两行显示(名称 + 缩写路径),让同名的 “2026” 不再混淆;“知识库内”是 Vault 里的真实目录。两组用同一个组件和交互。

只表达磁盘,不表达语义

统一用文件夹图标;展开态淡蓝填充;选中行浅蓝底 + 深蓝字;选中项的祖先加粗,一眼看出“我在哪条路径上”。层级用 16px 缩进 + 极淡的竖向引导线。

选中父级 = 看到全部后代

文件列表默认“含子文件夹”,面包屑可点击回退;切到“仅此层”才只看当前目录。数字是当前范围内的材料数,空目录淡灰显示,仍保留以忠实于磁盘。

操作就近放

悬停行出现 “…”(计数让位),菜单随根 / 子级不同:根可“从列表移除”(不删磁盘文件,菜单里明说),子级可“重命名 / 移到废纸篓”。新建走行内输入,不弹窗。

键盘与无障碍

role="tree" + roving tabindex;↑↓ 移动、→ 展开 / 进入、← 收起 / 回父级、Enter 选中、⌘⇧N 新建子文件夹。展开状态按用户记忆,下次打开原样恢复。

性能与深层目录

子层级在展开时才读取;超过 6 层时缩进步长由 16px 收到 12px,名称超长中间截断并在 hover 显示完整路径。目录读取失败的根显示红色底 + 就地“重新连接”。

3

文档右侧小标题(目录):不占宽度的“刻度轨”

所有 Markdown 浏览共用一个文档组件,所以只设计一套目录,在阅读 / 编辑 / 只读三种状态下仅做最小差异。默认只在右侧留白里露出一列细刻度(长短表示层级,蓝色 = 当前位置),悬停或聚焦才展开成浮动目录卡;想一直看,点“固定”变成 244px 侧栏。

  • 现状:44px 空白折叠轨 + 竖分隔线,没内容也占位
  • 现状:展开 220px 挤压正文列
  • 现状:标题单行省略,层级只靠 12px 缩进
  • 现状:编辑态与阅读态目录“跟随”逻辑不清
把鼠标移到窗口右侧的细刻度上;阅读态滚动正文,编辑态点击正文任意位置移动光标。

    三种状态只改这几处

    阅读态编辑态只读态(独立阅读窗口 / 历史版本 / 原文件不可用)
    当前位置跟随滚动(滚动监听,更新刻度与目录高亮)跟随光标所在章节,滚动不改变,避免打字时目录乱跳同阅读态
    点击目录项平滑滚到该标题,标题顶部留 24px滚到标题并把光标放到标题行末,正文不失焦同阅读态
    目录卡头部“目录 · N 节” + 固定按钮多一枚“跟随光标”蓝色标签;当前项右侧出现光标图标;底部显示 ⌘↑↓ 快捷键多一枚“只读”黄色标签;无光标、无快捷键
    窗口顶栏面包屑 + 保存状态 + 阅读 | 编辑同左;键入后显示“正在保存…”,完成后回到“已保存”用黄色徽章替换切换器与保存状态,写明原因(如“历史版本 3月2日 21:40”)
    正文17px / 1.85 宋体字体字号完全一致;Markdown 的 ## 记号悬挂在左侧留白,正文不位移同阅读态,可选中复制

    边界情形

    标题少于 2 个:不显示刻度轨,也不留任何占位,正文列保持居中。

    目录34 节

    标题很多(30+):刻度轨只画 H2,最多 14 条;卡片内 H2 可折叠其下的 H3,当前章节自动展开并滚入可视区。

    目录11 节

    窗口 < 980px:刻度轨改为点按展开(触控与键盘同样可达),目录卡覆盖在正文上方而不挤压;选中后自动收起。禁用“固定”。

    有关联 / 证据时:同一张卡顶部出现“目录 | 关联”切换,不再另开一块区域;没有关联时没有这个切换。

    为什么是“刻度轨”

    目录是导航的辅助,不是内容。默认零宽度占用,正文列 720px 与 24px 边距保持不变;刻度的长短提供“全文有几节、我在哪”的整体感,优于一个空白折叠轨。

    浮动卡的细节

    268px、14px 圆角、浮层阴影;H2 加粗为主、H3 缩进 14px 为辅;长标题换行显示(最多 2 行),不再单行省略。进入有 140ms 位移 + 透明度,尊重“减少动态效果”。

    可访问性

    刻度是 button,有“跳到「标题」”名称;卡片在 hover 与 :focus-within 都会出现;当前项 aria-current="location";固定状态与记忆偏好跨文档保留。
