# 代码架构审查与清理（2026-09-12）

本轮针对当前桌面与 Web 共用的产品实现审查和修复，不更改私人原始资料，也不重新设计演示故事。依据为实际入口、调用关系、已有架构检查、故障回归测试及安装包验收。未因文件名带 archive 或代码量大就删除仍在使用的实现。

## 架构结论

| 层 | 保留的职责 | 审查结果 |
|---|---|---|
| desktop | 窗口、IPC、系统能力、工作区初始化、本地服务生命周期 | 启动握手拆出可独立验证的模块；删除未使用的麦克风 IPC |
| web | 页面、共享展示、上下文发布，通过 API 访问数据 | 删除旧浮动 AI 面板分支；侧栏和独立窗口共用 AgentDock |
| server | 参数校验、路径边界、知识库切换、Run 编排、事件与监听 | 统一配置修改队列；限制后台任务、日志及事件流资源占用 |
| wiki-core / life-views | 文档解析、索引、只读外部来源、生活视图 | 保留现有领域边界和入口，无需另建抽象层 |
| run-manager / codex-bridge / shared | 任务快照与差异、协议、共享契约 | 保留按 Run 绑定的知识库上下文；修复进程启动错误与失败后重试 |
| knowledge-engine | 公共构建规则、双链与质量工具 | 仍以公共源为准，不将判断规则重写到 Studio |

既有依赖检查覆盖包公共入口、浏览器禁止 Node 依赖、shared 不反向依赖 feature、领域模块不依赖编排模块及运行时循环。没有发现需要拆分或合并现有领域 package 的证据。

## 已修复的发现

| 优先级 | 发现 | 处理 |
|---|---|---|
| 高 | Codex spawn 失败缺少 error 处理，命令失效时可能终止服务；初始化失败可能保留进程和 rejected ready | 统一拒绝待处理请求并释放状态；处理 stdin 错误；失败终止进程，允许重试；可用性探测限时 |
| 高 | 校验进程没有超时，日志在内存无限累积；exit 早于输出流排空 | 每条校验默认 120 秒；macOS/Linux 超时终止进程组；保存和实时输出各限 50,000 字符；在 close 后收集结果 |
| 高 | SSE 心跳与已接管响应没有统一关闭；慢客户端可持续积累缓冲 | 响应 close/error 清理心跳，服务关闭结束事件流，超过 1 MiB 缓冲断开重连 |
| 中 | 桌面服务超时只 reject，握手监听器继续存在，地址和输出没有约束 | 独立 waitForService：全部出口清理，失败 kill，限时及缓冲上限，仅接受 loopback 地址 |
| 中 | 麦克风权限等待期间可重复启动录音 | 增加启动中的互斥状态，finally 释放 |
| 中 | 页面卸载没有释放 AI 上下文，空页面可能保留上页内容 | PageAgentContext 只清理自己注册的上下文，避免覆盖后来页面 |
| 中 | 来源同步 setInterval 在慢扫描期间持续入队；监听错误被吞掉 | 上轮结束后再调度；监听失败写入连接状态供用户查看 |
| 低 | 旧浮动 Dock、遮罩、焦点陷阱、悬浮设置与新 Inspector 同时保留 | 删除旧分支、embedded 模式开关、包装组件和无效 launcher 字段，统一页面上下文发布 |
| 低 | 创建/删除知识库重复实现相同队列逻辑 | 复用 serializeMutation，与连接配置更新使用同一入口 |
| 低 | 架构描述仍声称依赖外部工作区提供知识引擎 | 修正文档，记录实际随包资源、数据边界及故障处理 |

## 删除范围

- 没有业务调用的 `detectImportSelectionKind` 与其专属类型、测试。
- 已经没有调用方的独立 `desktop:microphone` IPC；录音入口继续负责权限检查。
- 旧 AI 浮动按钮、模态遮罩、Tab 陷阱、配置 popover、相关 ref/state/props 与页面中的 launcher 元数据。
- 83 条只服务于上述旧面板或旧顶部导航的 CSS 选择器。混合选择器仅去掉失效分支，不删除仍有效的规则。
- 重复的知识库修改队列和桌面主进程未使用的导入。

保留了仍被照片识别、账单导入、来源引用、独立阅读、对话历史、旧知识库路径及 Web 运行使用的实现和依赖。特别是 archive 样式文件仍包含活跃的基础样式，不能整文件删除。
