桌面端全局 UX 重构设计稿

覆盖标题栏/侧边栏/命令面板等全局框架，以及此刻、生活记录、阅读编辑器、已有理解、搜索、聚焦工作区、AI 协作面板、偏好设置等全部桌面栏目。每个页面给出「现状问题 → 新方案标注 → 像素级规格表」，并在文末提供类名映射，方便工程直接对照实现。

01 · 原则

设计原则

借鉴 macOS / Apple HIG 的桌面软件质感，但不复制 Apple 皮肤，落成「The Way Here」自己的桌面语言。

① 一屏一主角

任何界面只保留一个视觉焦点（正文/文件列表/关系图），其余都是默认收起的辅助面板。

② 留白与字重分层，不是颜色分层

延续灰绿 + 暖金双色体系，压缩到「背景/内容/强调」三级对比。

③ 控件要够大够稳

列表主文字不低于 13px，点击目标不小于 28×28px。

④ 反馈要轻但确定

保存/同步用「淡入-停留-淡出」的轻提示，替代常驻小圆点文案。

⑤ 面板可收放且有动效

统一 200ms 宽度/透明度过渡，禁止瞬间消失/出现。

⑥ 统一圆角/阴影/分割线

全局 2 级圆角、1 套阴影 token，不再逐页覆盖。
