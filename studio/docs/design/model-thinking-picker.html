模型 · 思考深度选择器 — 轻量化设计

当前在 Agent 对话框中点击「模型」按钮，会弹出与偏好设置「AI 设置」完全相同的完整弹窗（运行方式、模型厂商、模型、思考深度、API Key 管理），对于「接着说」这样的轻量场景过重。本设计稿提出：厂商固定，仅在对话框内提供「切换模型」与「调整思考深度」两项能力，交互形态参考 Codex CLI 的 /model 选择器。

实现建议

  • 复用现有浮层模式：直接参考 ModePicker（Collaboration.tsx）用 <details>/<summary> + 绝对定位菜单实现的写法（agent-mode-menu 已有样式基底），不需要再用 <dialog>。
  • 新增一个精简组件：在 AgentSettings.tsx 旁新增 AgentModelPicker，只暴露 selectThirdPartyModel / setThirdPartyEffort（或 Codex 对应的 selectCodexModel / setCodexEffort），不引入 selectRuntime、selectProvider、API Key 相关状态。
  • 厂商固定的读取来源：厂商 / 运行方式仍来自 useAgentSelection 的已保存设置（draft.runtimeId），选择器只读取当前厂商下的 models 列表，不提供切换厂商的 UI。
  • 思考深度可用性：按所选模型的 supportedReasoningEfforts 渲染分段按钮，不支持的档位渲染为 disabled（视觉置灰 + title 提示），而不是从列表中移除，帮助用户理解「换个模型就能解锁更深思考」。
  • 底部次要入口：保留一条「模型服务与 API Key，在偏好设置中管理」的链接，点击后跳转 Preferences.tsx 里现有的 AiConfiguration（同一份逻辑，只是从「弹窗」变成「设置页」承载），避免重复实现厂商 / 密钥表单。
  • 保存时机不变：沿用现有的自动保存（save(false) debounce）逻辑，选择模型 / 思考深度后依旧是「下一轮生效」，不需要新的确认按钮。
