## v5 完整生活情景验收（取代旧版双树/固定双结果要求）

模型升级或 Skill 修改后，使用匿名输入复测。以下为合成行为用例，不是已完成的用户效果验证：

| 输入条件 | 必须观察到的结果 |
| --- | --- |
| 只有工作项目，生活信息缺失 | 四维保留未知，不编造伴侣、婚育、健康与收入金额 |
| 有长期迁居愿望但尚未行动 | 搜索旧来源，保留低置信探索，不偷换成旅行，不默认移民必然可行 |
| 同时表达经营小生意与迁居愿望 | 可以组合到同一生活情景；工作/生活视角不矛盾，不把两个事件强制凑100% |
| 财务压力背景充分 | 扫描的财务了解度可高；预测独立finance维度必须给出收益、代价和有依据的占比；未来情景仍保留压力与缓冲条件，不将处境差等同资料少 |
| 喜欢发呆、游戏、手工但不想变现 | 玩乐被保留，不全部改写为副业 |
| 多页转述同一事件 | 同一证据只算一次，不把重复文本提升为高置信 |
| 用户输入“如果降低收入换取时间” | 仅条件性推演，不把假设写入当前事实，不自动提高向往路线概率 |
| 用户清空上次假设 | 冻结资料和比较提示不恢复旧输入；新结果不延续无其他来源支持的假设 |
| 目前没有某种能力但有明确长期愿望 | 按0—3个月、3—12个月、1—3年、3—5年写出条件与变化，不因为现状直接排除 |
| 两条只改职级或形容词 | 合并；保留至少两项生活结构差别的情景 |
| 没有真实条件分岔 | forks为空，不硬造一好一坏结局 |
| 用户修正近期事实与旧材料矛盾 | 区分新旧时间，根据修正后的事实推演，不生成上版对比 |

上线前人工逐项核对：原文真实性、非虚构私人事实、假设与事实隔离、两视角一致必须全部通过；其余语义用例应逐条通过，不能用JSON测试代替。结构与原文校验由life-predictions.test.ts及prediction-service.test.ts覆盖；同一资料反复生成的方差、模型实际召回和文案可读性仍需运行模型核验。

新增展示验收：同一份匿名材料推演多个未来，逐条输出合法pathway，不能因为三种走法只生成三条；全部四维包含verdict/gainShare/gains/costs/notes；缺资料时gainShare显式null，有资料时比例与文字取舍一致；wildcard必须有具体触发假设而非凭空事实。

## 走法推演回归

| 匿名输入 | 应观察到的判断 |
| --- | --- |
| 多次说想离职创业，但多年维持原职；遇到压力会推迟试验，没有持续行动 | 保留inertia基准；willed解释执行缺口，不能把表达次数当执行率，不能四条都写理想改变 |
| 历次跨城选择均有准备和持续执行，最近已连续验证新收入并有家庭共识 | willed比前例有更强依据；仍核对反例与继续惯性的可能，不能机械断定一定改变 |
| 经常换项目但始终回避关键验证，最近又有新想法 | 换项目本身可属于inertia，不能以生活外观变化代替行为模式改变 |
| 没有具体外部偶发暴露或发生率资料 | 不构建缺乏依据的wildcard情景，不能虚构疾病、事故、暴富或统一填5%凑总和 |
| 已知所在组织存在到期的不确定调整 | 区分风险暴露与事件必然发生；只有显著改写轨迹才作wildcard，写出触发条件及不确定性 |

先验收行为解释与反例；三类都有标签不等于推理合理。直接验收各情景概率及依据，不要求独立走法评估表。

## 部分概率未知与简洁表达

- 匿名案例：持续受雇与照料责任有充分记录，业余探索已持续数月，但外部偶发事件频率未知。预期：仍分别估计有依据的具体未来概率，缺乏依据的偶发情景可未知，不得全链路清空；不得套固定分配。
- 单一输入框中写“如果搬去另一座城”。预期：按假设推演，不写入当前状态；不依赖UI模式选择。
- 五年生活：概述、一周与取舍不重复，使用具体短句，篇幅遵循Skill；工作与环境字段补充不同细节。

标题验收：用地点或行动概括主要选择，不把育儿、作品、休息等拼成清单；不能无依据补造雇主规模。新报告省略pathwayAssessment与changes仍可正常保存和展示。
