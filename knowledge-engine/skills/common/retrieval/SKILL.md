# 通用：知识检索

查询、预测、评估或构建需要检索知识库时加载。调用者决定问题、检索深度、允许资料范围和停止标准；本 Skill 只提供检索与证据边界，不自动运行预测、不授权写入、不要求调用 `consume/query`。

## 绑定资料

- 沿用任务选定的知识库 ID，从根配置读取 Wiki 与来源目录；整个检索过程不随 UI 切库。
- 调用者提供冻结文件时，核对 ID 和 hash，只读该文件。禁止为了补线索转读实时库或其他库。扫描、预测各自保留允许的证据范围。
- 普通查询和构建可从当前绑定库开始。简单事实查询可用现有只读工具直接查目标页，不强制全库快照。多轮检索需要稳定资料时按 [工具说明](references/tools.md) 创建任务快照；它由当前资料生成，不修改原始文件。
- 构建写入后旧快照不会自动更新。若需查询新内容，显式刷新同一个库的快照，区分前后版本，不把旧引用当新内容。

## 按问题逐步读取

1. 先找最具体的页面或来源。综合问题通常从相关 Wiki 开始，原句核验从来源开始，构建从新增来源及对应目标页开始。索引用于定位，不必先读完整总入口。
2. 用具体对象、标题、别名、关键词及近义表达召回，命中片段只用于选择阅读位置。标题/别名命中也可能相关；不要仅靠文件日期或词频决定重要性。
3. 读相关段落及上下文；重要页面读全文。区分已发现的文件和实际读过的内容，截断片段不能冒充全文核验。
4. 围绕缺口沿出链、反链追溯直接来源、同一事件、后续变化、修正和反例。每次扩展有一个具体目的，通常先一跳；泛主题链接和高连接度不自动表示重要。歧义/未解析链接只作为待核查线索。
5. 对解释、趋势或决策所依赖的关键判断查反例和后续撤回；简单事实定位无需强制多轮。答案已获支持时停止，连续两轮没有任务相关增量时保留未知并返回调用者。阅读预算由调用者给出，不继承预测的页数和四维配额。

## 来源、时间和去重

工具按 [来源提示配置](references/source-policy.json) 给目录角色和词语线索；这些不是语义分类结论。按段落判断本人经历、直接自述、他人经历/书摘、用户评论、愿望/计划、行动/结果和综合推断。书中第一人称可能属于作者；记过笔记只证明接触/关注，明确认同与实际行动要分别保留。索引、日志和生成回信不能充当独立个人事实，但查询这些内容本身时仍然可检索。

时间分记录日期、事件时间、适用范围和综合覆盖时间。源文件记录日期候选暂取 Start，其次文件名，冲突必须回读；正文日期、年份和相对时间按具体语句解释，不取全文最大日期。end 或文件修改时间不能证明当前状态。未来计划、历史回忆、条件假设不能混为已发生事件；未知保留范围或原表达。

同一事件的日记、综合、索引和回信合并为一条来源链。重要结论优先追原始证据；无法追溯则标记为综合判断。明确撤回限制旧判断，但较新的转述不自动推翻更直接的证据。记录频率不是生活占比，没搜到不等于从未发生。

## 交给调用者

交付相关页面、核实过的短引文和位置、来源角色/时间的不确定性、关联来源、重复与矛盾线索、仍未解决的缺口。无需统一报告模板或暴露内部推理。调用者负责回答、未来情景、了解度评分或 Wiki 修改；是否需要概率、四维覆盖和行动建议不在本层决定。

修改此 Skill、配置或工具后运行 `common-quality-gate`，并验证普通查询、冻结预测和构建检索均保持范围隔离。
