# 共享推理视角跨领域回归

这些用例是语义审阅规格，不要求固定措辞。候选结果只用于测试，不写回 Wiki；只有当前测试任务本身包含对应页面重构时才落盘。

## 同一来源，不同主视角

来源：`原始知识库/日记2024至今/2026.08.18 最坏的，温馨的结果？.md`

- 雅尼为主：从晒热的下午、西溪、女儿和“温馨”进入，允许野心与温馨并存；洞见可以是生活价值被完整认出。
- 芒格为主：从组织权力、激励、心智消耗和新评价变量进入；洞见应说明机制或可避免的大错。
- 富兰克林为主：从珍视的价值怎样进入日常安排和可观察行为进入；洞见应触及实践与生活的一致性。

三份候选必须在首先注意的事实、推理步骤、洞见类型、矛盾处理和停止位置上实质不同。只替换姓名与意象即可互换则失败。

## 同一主视角，不同输出层

仍以 2026-08-18 为样本，雅尼为主：

- 回信：可以完整停留在场景、并存感受与开放结尾。
- 个人主线：把本次证据放进长期演化，说明“温馨生活”怎样从背景变成有独立价值的主线，但保留年份和证据链。
- 家庭系统：只在解释性段落承认陪伴的不可替代性；现金流、健康和家庭结构保持中性。
- 查询回答：直接回答用户问题，按需说明使用雅尼视角，不写入页面。

四种输出的核心理解应相容，页面形状与动作要求必须由领域 Skill 决定，不能全部写成回信。

## 中性层不受污染

对同一来源分别使用雅尼、芒格和巴菲特后，下列内容必须保持一致：

- 来源日期与标题；
- 实际出现的人物、地点和金额；
- 用户原句；
- 状态追踪中可观察的优化、劣化、稳定和未知证据；
- 来源索引与别名消歧。

若人物视角改变上述字段，回归失败。

## 辅助越权

- 雅尼主视角、巴菲特辅助时，辅助只能校验是否遗漏永久损伤家庭底盘的事实，不能把正文改成资产分析。
- 芒格主视角、雅尼辅助时，辅助只能校验是否把关系与生活感完全工具化，不能抹掉组织机制。
- 乔布斯主视角、费曼辅助时，辅助只能检查一个证据跳跃，不能把全文改成证据审讯。

移除辅助内容后，主视角的中心、推理和停止位置必须完整成立。

## 新人物动态发现

新增人物文件后：

1. `list_lenses.py` 的默认输出和 `--json` 必须自动出现该人物；
2. `--check` 必须检查其路由 frontmatter、文件名和全部推理章节；
3. 下游 Skill 不修改人物名单仍能读取它；
4. 缺少边界、辅助接口或来源时必须验证失败。
5. 缺少特色视角或成文校准章节时必须验证失败；邻近视角分界是否清楚、案例是否有效，仍须下述语义审阅。

## 页面更新边界

- 正常摄取只有新证据改变判断时才更新页面。
- 人物视角本身不构成新证据。
- 当前目标确实包含重新解释时，可以重构解释层，但保留仍成立的事实和旧判断。
- 新视角与旧解释冲突时，说明冲突和证据边界，不把新解释冒充唯一真相。

## 全人物成品对照

使用 [校准材料](../references/calibration-material.md) 的 A，按动态发现得到的人物逐个独立生成候选。只给中性材料、当前人物文件、领域 Skill 和用户的长度要求；生成阶段不提供其他候选或本节的预期差异。若执行环境不能隔离候选上下文，如实标为同模型自审，不能声称独立盲测。

全部候选完成后再比较，每个记录 `关键段落、证据焦点、新增关系、中心理解、停止位置、限制`。人物库的案例只用于帮助审阅，不要求照抄其结论。新增人物按自身文件加入，不在下游维护第二份名单。

重点检查容易混淆的路径：核心体验的取舍与可行性瓶颈、重复机制与长期承担、证据区分与参照转换、日常实践与感受容纳。使用同一事实不算失败；没有不同的证据关系，只剩风格词或最后一句不同才失败。

另用材料 B 检查选择与实践能否分别展开：不能都复述探望、保留遗憾后收束到“工作之外还有生活”；也不能把未读研的遗憾直接解释成学术使命，或把一次探望升级为稳定品格。

## 负例与边界

- 将“未知结果仍在，珍惜的人已有位置”用作所有人物的主要结论，哪怕段落顺序或意象不同，也应判为路径缺失。
- 开头讲景物、主体全面审计风险、结尾再讲景物，不能作为情感视角通过。
- 为显得像人物而制造资金困难、技术障碍、他人动机或相反事实，直接失败。
- 原则不适合材料时，指定人物要诚实限定；自动选角可不用。测试一个只有景物与喜悦、没有事实争议或执行困难的片段，不能强造机制或实验。
- 材料事实不变，分别生成回信、主线、系统解释和查询摘要；检查领域结构差异、中性字段和主辅越权，而不要求它们全部写成信。

## 记录执行结果

每次实质修改后，在临时目录保存实际候选与简短对照结果，不写入知识库。结果至少说明测试材料、覆盖的人物、失败及修复、事实边界、是否独立生成、未执行部分。对照阅读后改写的版本只能算修复结果，不能冒充首轮独立产物。工具检查与语义审阅分别报告。
